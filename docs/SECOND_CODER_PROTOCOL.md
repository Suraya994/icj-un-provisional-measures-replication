# Independent post-publication revalidation protocol (optional)

No independent second coding forms part of the published analysis or this public release. If an independent reviewer later codes a blind sample, keep that dataset separate from the frozen published coding. Record reviewer ID, date, scope, blind instructions, pair-level codes and evidence pin-cites; then report agreement as a **post-publication revalidation**. Do not rewrite the provenance of the 2026 conference paper.
